# Farrukh Zaidi — Executive Web CV (Premium Edition)

Bespoke, high-end responsive Web CV and portfolio for **Farrukh Zaidi** (Section Head – Commercial Operations & Material Handling, Rajhi Steel, Saudi Arabia).

## Design & Architecture
- Styled with the exact luxury editorial magazine aesthetics, typography, and interactive components from the acclaimed Tanzila Farhat and Lohitha portfolios.
- **Color Progression**: Soft transition from Crisp Light Sky Blue (`#f0f6fc` ➔ `#e8f1fa`) through Mist Blend into Warm Linen / Paper Beige (`#f5f1e8`), culminating in Midnight Navy (`#0b1e38`) with atmospheric drifting orbs.
- **24-Element Periodic Table of Competencies**: Full interactive matrix with category filters and real-world industrial impact notes.
- **Interactive Browser Mockup & Initiatives Showcase**: Real-time project switcher with styled browser window and live tags.
- **Executive Attributes**: 3 custom graphical cards featuring geometric sketches, orbital rings, and sunset art.
- **3D Interactive ID Card**: Flips between corporate Rajhi Steel operational ID and VIP leadership dossier.
- **Spine Journey & Moments Snap Track**: Vertical career path and swipeable milestones carousel with animated counters.
- **Voice & Live Caption Briefing**: In-browser speech synthesizer with animated sound waves.
